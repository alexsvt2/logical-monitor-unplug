# Icono de Logical Unplug

Generado con la herramienta integrada OpenAI ImageGen el 13 de septiembre de 2026. Se conserva el PNG original con transparencia en `app-icon.png`; `AppIcon.icns` contiene las variantes de tamaño para macOS, convertidas con `sips` e `iconutil`.

## Prompt utilizado

Use case: logo-brand. Asset type: macOS application icon for Logical Unplug, a utility that disconnects a monitor from one computer by software so the monitor can switch to another computer. Create one polished square 1024x1024 icon, transparent outside a large rounded-square dark graphite tile with a restrained indigo-to-teal glow. Center a simple luminous silver desktop monitor silhouette, with a small clearly separated two-piece plug connection in front of the lower right of the screen suggesting logical unplugging. Premium macOS desktop icon, subtle dimensional beveled materials, crisp simple geometry, high contrast and readable at 32 pixels, generous margins. Straight-on view. No words, no letters, no numbers, no logos, no extra objects, no busy background. Deliver the icon itself, not a presentation mockup. Background outside tile must be genuinely transparent.
